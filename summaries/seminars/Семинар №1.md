# Байт-код и JVM-1
Программы транслируются в байт-код, выполняемый виртуальной машиной Java (JVM)

Название переменной может содержать $.

```java
Scanner in = new Scanner(System.in); // позволяет вводить данные из командной строки.
int a = in.nextInt();
double b = in.nextDouble();
```
